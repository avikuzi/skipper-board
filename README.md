# סקיפר-בורד

דשבורד לפני יציאה לים לסקיפרים בישראל: מזג אוויר ומדד Go/No-Go, צ'ק-ליסטים, אזהרות ניווט ומרינות, ויומן הפלגה.

## הרצה

```
npm install
npm run dev
```

`npm run build` יוצר את תיקיית `dist` לאירוח סטטי.

## מצב

- צעד 1 (שלד ומסך ראשי): בוצע. בחירת מרינת בית, מצב יום/לילה, שעות אור מחושבות, ספי בטיחות.
- צעד 2: תחזית מ-Open-Meteo ומפת Windy.
- צעד 3: צ'ק-ליסטים ויומן הפלגה.
- צעד 4: ניווט, מרינות ומחשבון הפלגה.
